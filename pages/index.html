Headcount is a web app for lobbyists, advocates and government affairs teams. It shows where every member stands, the odds a bill passes and whose mind to change next, then books the meeting, writes the brief and watches every capitol. The code is public: host it for your team, or build on it.

How it works

From the first count to the quarterly report

  1. Count

    Load the U.S. House, the U.S. Senate or any state chamber with current members and offices, and mark where each one stands.

  2. Prioritize

    Headcount ranks the members whose movement would change the outcome most, counting committee seats and who takes cues from whom.

  3. Meet

    Ask the scheduler for a meeting from your own Gmail or Outlook with open times from your calendar, then send the invitation when they reply.

  4. Report

    Log each contact as it happens. The activity report groups a quarter's contacts by client and issue for your disclosure filings.

Every seat, and what it means for the vote

  • Exact odds of clearing committee and the floor
  • Simple majority, three-fifths or two-thirds, to pass or to defeat

Meetings that actually get scheduled

  • Sent from your own Gmail or Outlook, to the scheduler who handles it
  • Three open times from your calendar, then a real invitation with a Meet or Teams link
  • Replies tracked, and a follow-up set for every request

A brief for every bill, ready for the meeting

  • Sponsors, status and the official summary from Congress.gov or Open States

And everything around it

The rest of the job, in the same place

Who else is lobbying

Federal disclosure filings that name your bill: which clients, which firms, what they reported. For contracts, who has won the work before.

Every relationship

Agency staff, coalition partners and client contacts with owners and a shared history. Personal emails from your inbox, logged on each contact.

Ready for a firm

Workspaces with roles and client guests, single sign-on with SAML or OIDC, an activity log, email digests, and per-seat billing through Stripe if you sell it.

Drafts, clearly marked

Claude drafts summaries, talking points and objections from the bill itself, labelled for checking before anyone relies on them.

Plain to run

A small Node.js server and one SQLite file. No web framework, no build step, no separate database. Every setting is an environment variable.

Run it

On your computer in two minutes

You need Node.js 22.13 or later. The development server has a test sign-in that accepts any name, so you can try teams and invitations right away.

$ git clone {{repo}}.git
$ cd headcount
$ npm install
$ npm run dev
# open http://localhost:3000

For your team, run the Docker image behind HTTPS with a persistent disk. The setup guide covers sign-in with Google Cloud Identity Platform, calendar and email access, email delivery, single sign-on, billing and the data source keys.

$ docker build -t headcount .
$ docker run -p 3000:3000 -v headcount-data:/data --env-file .env headcount
