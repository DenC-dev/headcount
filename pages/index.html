Know the count. Work the room. Run it yourself.

Headcount is a web app for lobbyists, advocates and government affairs teams: a seat-by-seat whip count with live odds, meeting requests from your own inbox, a brief for every bill, a monitor for bills, rules and contracts, a grassroots action center and a shared contacts list. The code is public. Host it for your team, or build on it.

What it does

From the first count to the quarterly report

The count, and what it means

Every seat in the chamber, colored by position, with the exact odds of clearing committee and the floor, and a ranked list of the members whose movement would change the outcome most.

  • U.S. House, U.S. Senate and any state chamber
  • Simple majority, three-fifths or two-thirds
  • Pass or defeat, committee and floor counted separately

Meetings that actually get scheduled

The request goes out from your own Gmail or Outlook with open times from your calendar. When the scheduler answers, the invitation goes out with a Meet or Teams link, and replies are tracked.

  • Calendar and email access stays in the browser
  • A follow-up is set for every request
  • Works without an account through your email app

A brief for every bill

Look up a federal or state bill to fill in sponsors, status and the official summary, then add talking points and objections yourself or have Claude draft them, clearly marked for checking.

  • See who else is lobbying on a federal bill
  • Prints cleanly as a leave-behind

Every campaign and client on one page

The portfolio shows each campaign's client, odds and weekly change, the next vote, meetings and overdue follow-ups, for the whole firm.

  • Workspaces with owners, admins, members and client guests
  • Lobbying activity report for disclosure work

The Monitor

Saved searches over new bills in Congress and all 50 states, Federal Register rules and SAM.gov contract notices, ranked against your priorities, with alerts when something matters or a tracked bill moves.

Action center

A public page per campaign: supporters enter their address, find which of your targets represent them, and write or call. Each letter shows beside that member in the count.

Contacts

Agency staff, coalition partners and client contacts with tags, owners and a shared history, and personal emails sent from your own inbox, logged on each contact.

For firms

Single sign-on with SAML or OIDC, joining by verified email domain, an activity log, email digests and per-seat billing through Stripe when you want to sell it.

Plain to run

A small Node.js server and one SQLite file. No web framework, no build step, no separate database. Every setting is an environment variable.

Yours to change

Plan limits, prices, rosters and data sources are ordinary files. Change what each plan allows in one place, or turn billing off for a single firm's copy.

Run it

On your computer in two minutes

You need Node.js 22.13 or later. The development server uses a test sign-in that accepts any name, so you can try teams and invitations right away.

git clone {{repo}}.git
cd headcount
npm install
npm run dev

Then open http://localhost:3000. For a real deployment, run the Docker image behind HTTPS with a persistent disk:

docker build -t headcount .
docker run -p 3000:3000 -v headcount-data:/data --env-file .env headcount

The setup guide covers sign-in with Google Cloud Identity Platform, calendar and email access, email delivery, single sign-on, billing and the data source keys.
